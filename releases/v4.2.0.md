# @altkit/discord v4.2.0

This release syncs the fork with the current Discord API v10 documentation and types. It adds the new channel
spoilering surface, file-type restrictions for file upload components, and the latest REST error codes, and ships
`ChannelFlags` as a first-class package export.

Altkit Discord remains user-account-only and continues to target the Discord.js `14.27.0` API surface where it
applies to this fork.

## Highlights

- Updated `discord-api-types` to `0.38.52` and `@discordjs/rest` to `2.6.3`.
- Added the full v10 `ChannelFlags` set, including `IS_SPOILER_CHANNEL` (2,097,152) and
  `HIDE_MEDIA_DOWNLOAD_OPTIONS`.
- Exported `ChannelFlags` from the package root so channel flags can be resolved and inspected by name.
- Added `flags` support to `guild.channels.create()`, matching the channel create request body and enabling
  spoiler channel creation.
- Added `file_types` support and a `setFileTypes()` helper to file upload modal components.
- Added the new v10 REST error codes `40009`, `20015`, `50167`, and `340015`.
- Regenerated the API reference and expanded the guide, compatibility, and release documentation.

## Discord API v10 sync

The API reference follows Discord's v10 documentation:

| Area                     | Change                                             |
| ------------------------ | -------------------------------------------------- |
| Channel flags            | `IS_SPOILER_CHANNEL` and the unstable flag set     |
| Channel create           | `flags` forwarded in the POST body                 |
| File upload components   | `file_types` serialized in modal payloads          |
| Application              | `flags_new` (string bitfield) already supported    |
| Interactions             | `app_permissions` on resolved channels             |
| REST error codes         | `40009`, `20015`, `50167`, `340015` added          |
| Message attachments      | spoiler, title, duration, and waveform metadata    |

## Spoiler channels

Discord spoiler channels are created or edited through the channel flags bit field:

```js
const { ChannelFlags } = require('@altkit/discord');

const spoilers = await guild.channels.create('season-finale', {
  type: 'GUILD_TEXT',
  flags: [ChannelFlags.FLAGS.IS_SPOILER_CHANNEL],
});
```

Read the spoiler state back from a channel's `flags` bit field.

## File upload components

Modal file upload components can now restrict accepted file types:

```js
upload.setFileTypes('image', '.png', '.jpg');
```

`setFileTypes()` accepts `FileUploadType` values (`'audio'`, `'image'`, `'video'`, or dot-prefixed extensions),
up to 10 entries, and serializes them as `file_types` in the v10 modal payload.
